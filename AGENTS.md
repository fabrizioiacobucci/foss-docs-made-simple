# Agents

Instructions for coding agents working in this repository.

- Before any change, read [CONTRIBUTING.md](CONTRIBUTING.md): it holds the rules for commits (DCO sign-off with `git commit -s`, Conventional Commits), tests, changes to the framework and releases.
- Before committing, run `scripts/tests/run.sh`, `scripts/check-links.sh` and `scripts/check-copies.sh` from the repository root.
- Scripts stay in Bash with no other dependencies, and work with Bash 3.2 and BSD tools as well as with GNU tools ([arc42 section 8](docs/architecture/08-crosscutting-concepts.md#test-strategy)).
